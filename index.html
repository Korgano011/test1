How to add an App Clip to a Build

1. Have the demo video show what the app does

  • Give the demo video a name.
  • Add the demo video to the project folder.
  • Keep the demo video small. The whole App Clip must be 15 MB or below.

2. Add the App Clip target in Xcode

  • File ▸ New ▸ Target… ▸ iOS ▸ App Clip ▸ Next.
  • Product Name: <clip name> • Team: <team number> • Interface: SwiftUI • Embed in Application: <app name>
  • The bundle ID must begin with the app’s ID: com.username.AppName.Clip
  • Click “Activate” when Xcode asks about the new scheme.
  • Check that the app target ▸ Build Phases now has Embed App Clips containing <clip name>.app.
  • Don’t set the clip’s deployment target higher than the app’s.
  • Set the App Clip’s version. Make sure it matches the app version.

3. Clip code and files

  • <Clip Folder>/<ClipName>App.swift: the @main app that shows the demo view.
  • <DemoView>.swift: the view that plays the demo video.
  • Give the demo view file membership in both targets, or copy it into the clip folder.
  • Copy the demo video (for example <demo video>.mp4) into the clip folder. Copy it; don’t move it. Then check Target Membership in the File inspector: the clip only.
  • Don’t put the demo video in the app’s folder unless the full app should ship it too.
  • Add an App Clip icon for the App Clip target.

4. Entitlements, Info.plist and privacy

  • App entitlements:
    com.apple.developer.associated-appclip-app-identifiers = $(AppIdentifierPrefix)com.username.AppName.Clip
    Xcode usually adds this itself; check that it’s there.
  • Clip entitlements:
    com.apple.developer.parent-application-identifiers = $(AppIdentifierPrefix)com.username.AppName
    The template also adds com.apple.developer.on-demand-install-capable.
  • Clip Info: set ITSAppUsesNonExemptEncryption = NO (the same INFOPLIST_KEY setting as the app).
  • Add PrivacyInfo.xcprivacy to the clip folder. If the clip only plays video, it collects no data and needs no required-reason APIs (add UserDefaults CA92.1 only if the clip uses it).
  • The clip needs no camera, microphone, speech or photo usage strings. If Xcode lists any for the clip target, remove them.

5. Size check

  • Product ▸ Archive, then Distribute ▸ Custom ▸ App Store Connect ▸ Export, and turn on the App Thinning size report.
  • Keep the clip’s uncompressed thinned size under 15 MB so it works with every type of invocation.

6. Build and test

  • Choose the <clip name> scheme, run it on an iPhone simulator, and check that the video plays and the Get button shows the overlay.
  • Optional: in the scheme’s Run ▸ Arguments, set the environment variable _XCAppClipURL = https://appclip.apple.com/id?p=com.username.AppName.Clip to test a launch from a link.
  • Choose the <app name> scheme and build Release for iOS, which also builds the clip. Check that there are no errors.
  • Run it on your real iPhone with both schemes. Automatic signing registers the clip’s bundle ID and profile.
  • Deleting the clip from the phone must not delete the full app, and the full app should still work as before.

7. Archive and upload

  • Product ▸ Archive with the <app name> scheme. In Organizer, check that the archive contains Products/…/<app name>.app/AppClips/<clip name>.app.
  • Distribute App ▸ App Store Connect ▸ Upload, then wait for the processing email.
  • Optional: test the clip in TestFlight. App Store Connect ▸ TestFlight ▸ build ▸ App Clip ▸ add an invocation URL.

8. App Store Connect – App Clip experience

  • On the version page, select the new build. An App Clip section appears below it.
  • Header image: 1800 × 1200 px PNG or JPG, no transparency (for example, a frame from the demo video with the app name).
  • Subtitle (up to 56 characters), for example: “See what the app does before you download.”
  • Action: View (or Open / Play).
  • Use the Default App Clip Experience only. Advanced experiences (your own website URL, NFC or QR codes) need an apple-app-site-association file and can wait.
  • Add a line to the App Review notes, for example: “Includes an App Clip (<clip name>) that plays a demo video and links to the full app.” Keep the notes under 4,000 characters.

9. Submit

  • App Privacy answers stay “Data Not Collected” if the clip collects nothing.
  • Add for Review ▸ Submit.
  • After approval, check that the default App Clip link opens the clip on a phone that doesn’t have the app installed.
